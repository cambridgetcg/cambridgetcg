    02 / TRANSLATE THE PATTERN

    Give the idea
    some load-bearing walls.

    ◌

    Topology → welcome

    Make help reachable without making every relationship compulsory. Leave a door open; let someone choose not to walk through it.

    Build: discoverable public entry points, explicit invitations, a complete decline path.

    ⌁

    Curvature → adaptation

    Let the path bend around another person's context. Keep their account beside yours instead of replacing it with your preferred summary.

    Build: attributed reports, selected context, visible disagreement and corrections.

    ↶

    Boundaries → care

    An edge can end without a node becoming less welcome. A pause is not a broken connection that the system must repair.

    Build: expiring scope, one bounded act, a stop button and no automatic retry.

    Topology and curvature guide the design. This page neither proves that love is a mathematical object nor computes anyone's love or understanding.

    2. 02

      A context you choose

    3. 03

      One finite act

      Use Agent Workbench for a saved workflow with explicit steps, a time limit and a stop path. An accepted invitation still needs the host's permission to act.

    4. 04

      Local Collab records scoped claims, evidence and corrections. A handoff can be declined. A different session reviews reported completion.

      Run the checks, publish only the chosen artifact, then read the live bytes back. Preserve a failed check as evidence for repair, not a success-shaped story.
